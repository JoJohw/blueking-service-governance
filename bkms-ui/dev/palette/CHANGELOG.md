# 更新记录

## 2026-11-19

### 新增

- **搜索覆盖三个视图**：圆角与可视化视图接入顶部搜索，作用域为当前视图的分组；结果按视图分块——颜色为色阶 / 语义层，圆角为档位 / 圆角语义，可视化按语义场景各自成块。
- 搜索框与结果区抽为 `SearchBar` / `SearchResults` 两个纯展示组件；`util/search.ts` 去掉全局注册表，改为纯函数 `searchTokens(groups, query)`，不再认识视图分类。
- 卡片复制改为**实际值优先**，面向设计师：点击卡片复制 hex / 半径 / 阴影效果串，右上角 `var()` 按钮复制 CSS 引用供开发使用。`resolved()` 的解析池由颜色扩展到圆角与 viz 三份令牌，圆角语义档也能解出长度值。

### 修复

- 修复键盘激活 `var()` 按钮会复制成卡片实际值：按钮移出 `role="button"` 容器、与外层卡片的 keydown 处理隔离，同时修掉 `button` 角色被吞掉的无障碍问题；无 hover 的触屏设备上按钮改为常显，卡片聚焦时也会显示。
- 修复色值建议首次选色后面板向下铺开、溢出视口：面板下沿改为固定贴着悬浮胶囊的快照位置，内容变高时用 `ResizeObserver` 同步上移（向上生长），并给面板加 `max-height` + 内容区单一滚动兜底；阈值脚注移出滚动区常驻底部。

### 变更

- 圆角档位由数字名 `3/4/6/8` 改为量级刻度 `hairline/xs/sm/md/lg/xl`（1/3/4/6/8/20px），另加形状档 `none`（直角）与 `full`（正圆 / 胶囊）；语义层改为 `var()` 引用档位，不再绑死像素值。
- 圆角视图的分组描述与语义说明改为业务场景写法（「输入类控件外框」「浮层外框」等），`indicator`（告警记录级别色标）与 `tile`（空态页 logo）按实际使用场景描述。
- 圆角视图补形状档小样：`none` 渲染直角方框，`full` 并排渲染正圆与胶囊；尺度档仍走三尺寸方框。
- 圆角视图移除 `checkbox` 小样：该语义档已随档位重构删除，模板分支与样式不可达。
- 可视化视图分组标题改为直白说法（线条 → 连线、面 → 底色、状态 → 节点状态、图表 → 图表结构、选中态 → 选中高亮、分类色 → 曲线配色），分组描述与令牌说明按「出现在哪个页面、哪块地方」重写。
- 曲线配色的小样由平铺的八色带改为一张八条曲线的迷你折线图（被审视的那条加粗），让「这组色是给折线图曲线用的」一眼可见。

## 2026-11-18

### 新增

- **可视化字典视图**：左侧顶部新增「可视化」入口，按线条 / 面 / 状态 / 文字 / 图表 / 选中态 / 分类色七个场景分组展示 `viz.css` 令牌；每组渲染对应形态的仿制小样（三种笔形连线、画布与卡片、minimap 状态块、浅深双底文字样张、带网格与浮层的迷你折线图、节点选中描边、八色分类色带），分类色标注「锁定」。
- 圆角视图补 `--bkms-radius-base` 的通用基准方框小样。

### 变更

- 视图由二元扩为三元：标题、分组导航、专注模式与 `?focus=<分组名>` 参数随视图切换；切换时清空搜索与专注并回到顶部，搜索仍为颜色视图专属。
- `menu` 语义档改指 6px，圆角小样的 fallback 同步为 6px。

## 2026-11-17

### 新增

- **分组标记**：token 文件改用 `@group`（开组，值即分组标题）/ `@note`（分组描述，可多行，`@description` 同义）/ `@endgroup`（闭组）显式标记分组边界，分组描述展示在标题下方。
- 阴影令牌新增 `--bkms-shadow-float`（画布浮层、工具条、节点卡片）与 `--bkms-shadow-inset`（输入框、搜索框内阴影），阴影分组由 6 项增至 8 项。

### 变更

- 令牌文件按维度合并为 `color.css`（色阶 + 语义 + 阴影同文件），`semantic.css` 已删除：`@group` 块新增必填 `@layer`（`scale` | `semantic`）标记，工具据此区分色阶组与语义组，不再依赖文件名。分组缺标记或值非法时直接报错，避免整组静默消失。
- `colors.css` / `semantic.css` 的组名与描述改由 token 文件内的标记维护，工具不再依赖注释文本的固定句式。
- 分组只认 `@group`：普通单行注释一律当备注、不隐式建组；声明同行尾注释挂到对应 token，非 `@tag` 多行块注释兜底为组描述，未知 `@tag` 忽略不报错。
- 阴影分组归「语义层」（`semantic.css`）：阴影按场景命名、值即完整 8 位效果值，无法由色阶派生，随暗色主题整体覆盖；色阶区只保留原子色阶，生成器改为同时读两个令牌文件以保留 8 位精确匹配。
- 展示形态与分区解耦：`RampCell` / `SemanticCell` 合并为 `TokenCell`，卡片长什么样由 `previews` 规则表按 token 类别决定，分区只决定卡片尺寸与预览高度。新增类别只需加一条规则 + 一个预览组件。

## 2026-11-16

### 新增

- **色板浏览**：按色阶 / 语义层分组展示主题 token，点击色块复制 `var()`；语义 token 附带文字、线条、背景、阴影等实际预览。
- **顶部搜索**：输入即过滤，支持 token 名 / 用途 / 分组 / 引用，以及 hex、rgb()、rgba()、hsl()、hsla() 颜色值；结果按色阶 / 语义层分组，无匹配时给出空占位与快捷清空。
- **专注模式**：每组可单独进入专注，放大色块、标题吸顶；状态写入 URL 参数，刷新保持，退出回到原滚动位置。
- **色值建议工具**：右下角可拖动悬浮胶囊打开无遮罩面板，输入颜色后按 CIEDE2000 ΔE 列出贴近色板值（阈值 6），可复制 `var()`；胶囊与面板拖动支持边缘吸附。
- **复制提示**：顶部弹出成功提示，显示所复制的 token。

### 变更

- 工具界面配色改为 `shell.css` 中一组固定值，不随主题 token 变化；色块与预览仍取自 token 真源。
- 语义 token 的 `var()` 引用改为递归解析，支持多层引用并防止循环。
- 启动脚本命名为 `theme:designer`（`pnpm theme:designer`，端口 5300）。

### 修复

- 修复专注模式标题吸顶时滚动内容穿透的问题。
- 修复退出专注后不恢复原滚动位置的问题。
- 颜色搜索与建议池正确识别短写 hex（如 `#FFF`），避免色差计算失效。
- 修正 hsl() 越界输入产生非法色值的问题。
- 修正 `var(--bkms-xxx)` 形式无法被搜索命中。
