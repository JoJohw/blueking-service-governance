# 更新记录

## 2026-11-16

### 新增

- **色板浏览**：按色阶 / 语义层分组展示主题 token，点击色块复制 `var()`；语义 token 附带文字、线条、背景、阴影等实际预览。
- **顶部搜索**：输入即过滤，支持 token 名 / 用途 / 分组 / 引用，以及 hex、rgb()、rgba()、hsl()、hsla() 颜色值；结果按色阶 / 语义层分组，无匹配时给出空占位与快捷清空。
- **专注模式**：每组可单独进入专注，放大色块、标题吸顶；状态写入 URL 参数，刷新保持，退出回到原滚动位置。
- **色值建议工具**：右下角可拖动悬浮胶囊打开无遮罩面板，输入颜色后按 CIEDE2000 ΔE 列出贴近色板值（阈值 6），可复制 `var()`；胶囊与面板拖动支持边缘吸附。
- **复制提示**：顶部弹出成功提示，显示所复制的 token。

### 变更

- 工具界面配色改为 `shell.css` 中一组固定值，不随主题 token 变化；色块与预览仍取自 token 真源。
- 语义 token 的 `var()` 引用改为递归解析，支持多层引用并防止循环。
- 启动脚本命名为 `theme:designer`（`pnpm theme:designer`，端口 5300）。

### 修复

- 修复专注模式标题吸顶时滚动内容穿透的问题。
- 修复退出专注后不恢复原滚动位置的问题。
- 颜色搜索与建议池正确识别短写 hex（如 `#FFF`），避免色差计算失效。
- 修正 hsl() 越界输入产生非法色值的问题。
- 修正 `var(--bkms-xxx)` 形式无法被搜索命中。
